# تطبيق إدارة الحضور وحساب الراتب (KS Attendance)

تطبيق أندرويد حديث مبني بالكامل باستخدام **Jetpack Compose** و **Material 3** وفق أحدث معايير تطوير الأندرويد، مخصص لتتبع الحضور والانصراف، حساب ساعات العمل الفعلية، واحتساب الراتب الشهري بدقة.

---

## 🌟 المميزات الرئيسية

1. **العمل أونلاين وأوفلاين (Dual Mode)**:
   - **الوضع اليدوي (Offline)**: تسجيل حضور وانصراف بضغطة زر مع مؤقت زمني مباشر للجلسة الحالية.
   - **الربط مع نظام المطعم (ESS Online)**: إمكانية تسجيل الدخول بحساب ESS ومزامنة البصمات والورديات تلقائياً (مبني على تحليل البروتوكول من السكريبت الأساسي).

2. **المرونة الكاملة في التعديل والإضافة**:
   - إمكانية إضافة سجل حضور يدوي بأثر رجعي لأي يوم.
   - تعديل أو حذف أي وردية (تعديل وقت الدخول أو الخروج أو التاريخ).
   - حل مشكلات عدم قراءة البصمة أو الأخطاء في السيستم بكل سهولة.

3. **حساب الراتب ودورة المرتب**:
   - إمكانية تغيير سعر الساعة في أي وقت من الإعدادات (الافتراضي: 30 ج.م/ساعة).
   - تخصيص دورة المرتب الشهرية (مثلاً: من يوم 29 حتى 28 من الشهر التالي، أو من أول الشهر 1 حتى نهايته).
   - حساب إجمالي الساعات وأيام العمل والراتب الصافي المتوقع للفترة المحددة.

4. **ملاحظات الأيام (Notes)**:
   - كتابة ملاحظات مخصصة لأي يوم محدد (ساعات إضافية، تأخير بسبب ظرف معين، وردية خاصة، إلخ).
   - استعراض الملاحظات وتعديلها أو حذفها.

5. **التقويم الشهري الذكي (Calendar)**:
   - واجهة تقويم مخصصة بالكامل بـ Compose (بدون مكتبات خارجية).
   - تمييز الأيام التي تم العمل فيها بالأخضر، الأيام الفارغة السابقة، اليوم الحالي، والأيام التي تحتوي ملاحظات بنقاط زرقاء.
   - الضغط على أي يوم يفتح قائمة سفلية (Bottom Sheet) بتفاصيل اليوم وإمكانية إضافة ملاحظات أو سجلات جديدة.

6. **التقارير والتصدير**:
   - رسم بياني مخصص (Bar Chart) مرسوم بـ Canvas لعرض ساعات العمل اليومية لآخر أسبوعين.
   - تصدير كامل البيانات إلى ملف **CSV** متوافق مع Excel واللغة العربية (UTF-8 BOM).

7. **واجهة مستخدم عصرية مخصصة**:
   - لا تعتمد على أي مكتبات خارجية للواجهة (Pure Jetpack Compose + Material 3).
   - دعم كامل للغتين (العربية والإنجليزية).
   - دعم الوضع الداكن والفاتح (Dark Mode / Light Mode).

## 🏗️ البنية البرمجية (Architecture)

```
com.ks.attendance/
├── KSApp.kt                          # فئة التطبيق الرئيسية
├── MainActivity.kt                   # النشاط الرئيسي مع Jetpack Compose
├── data/
│   ├── local/                        # قاعدة البيانات المحلية (Room)
│   │   ├── AttendanceDatabase.kt
│   │   ├── dao/
│   │   │   ├── AttendanceDao.kt      # استعلامات السجلات
│   │   │   └── DayNoteDao.kt         # استعلامات الملاحظات
│   │   └── entity/
│   │       ├── AttendanceRecord.kt   # جدول الحضور والانصراف
│   │       └── DayNote.kt            # جدول ملاحظات الأيام
│   ├── remote/                       # الربط الشبكي مع ESS
│   │   ├── EssApiClient.kt           # عميل OkHttp لمزامنة السيرفر
│   │   ├── EssModels.kt              # نماذج البيانات
│   │   └── ClockingParser.kt         # خوارزمية دمج وتوفيق بصمات الدخول والخروج
│   └── repository/
│       └── AttendanceRepository.kt   # طبقة البيانات الموحدة
├── ui/
│   ├── MainViewModel.kt              # إدارة الحالة والتفاعل (State Management)
│   ├── navigation/
│   │   └── KSNavGraph.kt             # التوجيه والتنقل والشريط السفلي
│   ├── components/
│   │   └── CommonComponents.kt       # المكونات المشتركة (بطاقات، حوارات، أزرار)
│   ├── screens/
│   │   ├── home/HomeScreen.kt        # الشاشة الرئيسية والزر الكبير
│   │   ├── attendance/AttendanceListScreen.kt # سجل الحضور الكامل
│   │   ├── calendar/CalendarScreen.kt # التقويم الشهري
│   │   ├── record/AddEditRecordScreen.kt # إضافة وتعديل سجل
│   │   ├── reports/ReportScreen.kt   # التقارير وحساب الراتب والتصدير
│   │   └── settings/SettingsScreen.kt # الإعدادات وسعر الساعة ودورة الراتب
│   └── theme/
│       ├── Color.kt                  # باليتة الألوان المخصصة
│       ├── Theme.kt                  # إعداد الثيم الفاتح والداكن
│       └── Type.kt                   # الخطوط والتنسيقات
└── utils/
    ├── DateUtil.kt                   # دوال معالجة التاريخ والأسماء بالعربية
    ├── ExportUtil.kt                 # تصدير ملفات Excel/CSV
    ├── PayrollUtil.kt                # خوارزمية حساب دورة الراتب
    └── PrefsUtil.kt                  # حفظ التفضيلات والإعدادات (DataStore)
```

## 🚀 كيفية التشغيل والفتح

1. افتح المشروع عبر **Android Studio** (Koala أو Ladybug أو أحدث).
2. قم بمزامنة الـ Gradle (Sync Project with Gradle Files).
3. اختر محاكي (Emulator) أو هاتف أندرويد حقيقي، ثم اضغط **Run (Shift + F10)**.
